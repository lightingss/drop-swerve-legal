Privacy Policy

This policy applies to Drop & Swerve for iPhone, iPad and any App Store build published by the developer. It describes what the shipping game does. If a future update adds a new data flow, this policy and the App Store privacy answers will be updated before that build is submitted.

English

Data stored on your device

Drop & Swerve is a single-player game. The game stores the following locally on your device using Apple NSUserDefaults / Unity PlayerPrefs:

  • language choice;
  • the eight-hour clock, ending and achievement state;
  • best run record and unlocked local achievements;
  • the developer-tip preview state and anonymous supporter ID;
  • a local mock-ad state used only to demonstrate the ad surface.

This data is not sent to a server. Deleting the app removes it. The game has no account, login, chat, user-generated content or analytics SDK.

Purchases

Optional developer tips are processed by Apple In-App Purchase. The developer does not receive your name, email, card details or Apple ID. The app may retain the transaction identifier and app receipt on-device so a purchase can be restored or verified. Apple's privacy policy applies to payment processing.

The current build does not operate a live global supporter board. If one is enabled in a future build, only an anonymous supporter token, preset display name, non-spendable rank points and a public/private flag would be sent after Apple receipt verification. The game will never publish an Apple ID, email, device ID or payment details.

Advertising and tracking

The current build uses a local mock ad surface, clearly labelled as a development test, and collects no advertising data. If a real advertising SDK is enabled in a future build, the required consent flow (including Google UMP in the EEA/UK/Switzerland and Apple ATT only if cross-app tracking is actually used) will be presented first, and this policy plus App Store privacy answers will be updated.

Game Center

Game Center is optional. If you sign in, Apple handles your Game Center identity; the game submits a run score and reads leaderboard ranks. The game is fully playable without signing in.

Hosting of this policy

This policy is hosted by GitHub Pages. GitHub may process standard web-request information (such as IP address and user agent) under GitHub's own privacy statement. The game does not send your game data to GitHub.

Children

The game is intended for a general audience and does not knowingly collect personal information from children. There are no accounts, chat rooms or user-generated content.

Your choices and deletion

You can delete all local game data by deleting the app. For a privacy request, email chinagdh@163.com. If a global supporter row is ever enabled, the support page will provide a deletion control.
